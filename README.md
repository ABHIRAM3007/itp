# The Ultimate AI Roadmap

A zero-to-industry roadmap for becoming an **AI Engineer / ML Engineer / Deep Learning Engineer / LLM Engineer**.

Start here: **[AI_ROADMAP.md](AI_ROADMAP.md)**

## What's inside

Every topic is a self-contained Markdown file with 26 sections: intuition, math, formulas, algorithm, from-scratch code, library code, complexity, advantages / disadvantages, interview questions, common mistakes, optimization, exercises, mini / medium / advanced projects, and industry usage.

- **Phase 0** — Prerequisites (Python, Linear Algebra, Calculus, Probability, NumPy/Pandas)
- **Phase 1** — Classical ML (Regression → Trees → Boosting → SVM → PCA → Feature Engineering)
- **Phase 2** — Deep Learning (MLP → Backprop → CNN → RNN → Attention → Transformer → AE → GAN)
- **Phase 3** — NLP & LLMs (Tokenization → Embeddings → BERT/GPT → RLHF/DPO → LoRA → RAG → Agents)
- **Phase 4** — Computer Vision (Classification → Detection → Segmentation → Diffusion → Multimodal)
- **Phase 5** — MLOps (Tracking → Serving → K8s → CI/CD → Monitoring → Feature Stores → LLMOps)
- **Phase 6** — Advanced (RL → Interpretability → Distributed Training → Compression → Safety)

## Suggested workflow

1. Read `AI_ROADMAP.md` end-to-end for the map.
2. Work topic-by-topic in `roadmap/phase-*/`.
3. Do at least one project per topic; build the phase capstones.
4. After each topic, drill the interview questions aloud.

Ship things. Read papers. Repeat.
